# Archived figure assets

On 2026-10-24, files not referenced by the active LaTeX input tree rooted at
`sigconf.tex` were moved here. The audit includes the main text, appendix,
and supplementary material. The 16 currently included figures remain in
`figures/`.

This archive contains 27 previously top-level assets and the 76 files from
the former `figures/alternatives/` directory, with their relative paths
preserved. Nothing was deleted. Commented-out references and the unused
figure component point to the archived files so they can be re-enabled.

To recover an original location, remove `NOT_USED/` from the archived
path. The `alternatives/` subdirectory retains its previous Git-ignore
status; these local alternatives are not automatically included in a push.
